Okaeri_Master
"ยินดีต้อนรับกลับค่ะ นายท่าน!" 
ประเภทโครงงาน: Social Media Platform   
ที่มาและความสำคัญ ในชีวิตประจำวันผู้คนอาจเผชิญกับความเครียดจากการเรียน การทำงาน และปัญหาส่วนตัว ซึ่งอาจทำให้รู้สึกเหนื่อยล้า เหงา หรือต้องการพื้นที่ระบายความรู้สึกและพูดคุยกับผู้อื่น โครงงานนี้จึงมีแนวคิดในการพัฒนาแพลตฟอร์มสังคมออนไลน์ที่ผสมผสานการพูดคุยทั่วไปเข้ากับการสวมบทบาท (Roleplay) ภายใต้บรรยากาศที่ได้รับแรงบันดาลใจจากความสัมพันธ์ระหว่าง Master/Mistress และ Maid/Butler โดยเน้นการสร้างประสบการณ์ที่ให้ความรู้สึกเหมือนได้กลับมายังพื้นที่ส่วนตัวที่มีผู้กล่าวต้อนรับ เช่น “ยินดีต้อนรับกลับค่ะ นายท่าน” เพื่อช่วยให้ผู้ใช้รู้สึกผ่อนคลายและเพลิดเพลินกับการพูดคุย โดยผู้ใช้ไม่จำเป็นต้องสวมบทบาทตลอดเวลา
